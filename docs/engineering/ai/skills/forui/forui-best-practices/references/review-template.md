## Migration Plan

1. Pick one boundary.
2. Replace the old implementation with the Forui implementation.
3. Remove obsolete adapters, wrappers, and duplicate state.
4. Run format, analyze, tests, and a focused visual or interaction check.
5. Commit the boundary before moving to the next one.
